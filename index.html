Research

At the University of Florida’s Smart Autonomy Lab, I study program behavior and robot learning.

Binary code similarity

I co-develop methods to assess whether patched or recompiled binaries preserve functional and security behavior without source code. My work includes baselines, training and evaluation across compiler, optimization and architecture variants.

Cross-embodiment robot learning

I develop methods to transfer manipulation policies learned on one gripper to collaborative robot arms with different gripper geometries, and test whether trajectory resampling can adapt demonstrations to a new gripper.

Vision-language-action systems

I work on a framework that breaks complex instructions into simpler prompts for a vision-language-action policy, with a verifier to detect failures and support recovery.

Turnout Planner

A barn’s daily turnout board, built from an open-ended take-home brief. Set up horses, spaces and recurring groups, generate the day from the schedule, then run it live: what went out, when and where, and which horses shouldn’t share a paddock. A 3D map of the barn shows where every horse is right now.

Next.js, React and TypeScript, Prisma on Postgres, Three.js for the map and Open-Meteo for the barn’s weather.
